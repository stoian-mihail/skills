# skills

Agent skills for Kimi Code CLI (directory form: one folder per skill, SKILL.md inside).

- **codemap** — map a codebase module as a flow-ordered markdown code map (`.codemaps/<slug>.md`)
- **dont-rust** — pair-programming mode: the agent maps, plans every line, dictates while the user types
- **hold-your-horses** — toggle: answer every user question, including rhetorical ones, before continuing

## Install

Clone and point Kimi Code at the folder, or copy the skill directories into `~/.kimi-code/skills/`.
